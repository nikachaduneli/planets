# The Planets

This is a simple HTML, CSS, and JavaScript project that displays information about the planets in our solar system. It fetches data related to each planet and presents it in a structured and interactive way. The application includes details such as overview, internal structure, surface geology, and other key planet statistics like rotation time, revolution time, radius, and average temperature.

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

The project consists of the following files:

- `index.html`: The main HTML structure that holds the content.
- `style.css`: The stylesheet for the layout and design.
- `js/`: A folder containing JavaScript files:
  - `render.js`: Handles the rendering of planet information and images.
  - `router.js`: Manages navigation and routing between different planet sections.
  - `main.js`: Handles the overall functionality and interactivity of the app.

## How to Use

1. Clone the repository or download the files.
2. Open the `index.html` file in your browser.
3. Click on any planet name in the navigation bar to display its information.
4. Use the options to explore different sections like the overview, internal structure, and surface geology.
